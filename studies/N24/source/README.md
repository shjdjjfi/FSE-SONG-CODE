# FSE-EXP-1 — N24 experimental branch

This **`n24-fse-benchmark` branch** holds the experimental materials for Idea N24:
*Measuring Collateral Version Churn When Repairing npm Platform Lockfiles*.

- [Research methods, commands, and limitations](n24_submission_experiments/README.md)
- [Frozen research decisions](n24_submission_experiments/preregistration.json)
- [Cross-platform GitHub Actions jobs](.github/workflows/n24-cross-platform.yml)
- [Public historical repository sample](n24_submission_experiments/historical_sources.json)

The repository's `main` and `n21-fse-benchmark` branches remain separate and untouched.
Controlled npm regressions and replays of public committed lockfiles **must not** be
described as naturally occurring industrial CI events. Original production
incidence, labor minutes, and monetary ROI are not measured here.
