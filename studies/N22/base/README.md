# FSE-EXP-1 — N22 experiment branch

This `n22-fse-industry` branch contains a self-contained, public-case
experimental replication package for N22:
**[Checking Data Contracts Across Converging Database Migration Paths](N22/README.md)**.

The N21 TypeScript build-output experiments belong to the separate
`n21-fse-benchmark` branch; the default branch is not changed by this work.

Read the [N22 experimental report](N22/EXPERIMENT_REPORT.md) and
[evidence gaps](N22/SUBMISSION_GAPS.md) before reusing any numbers.
This is controlled research on public source and synthetic inputs, not a
claim of access to production databases or measured industrial incidents.
